Case Study 1: Student Dashboard
Aim
To design and develop a student dashboard that displays student details, semester results, attendance percentages, subject information, examination schedules, and announcements.
Description
The student dashboard provides a simple and organized interface for students to view their academic information. It uses tables to display semester results and subject details, progress bars to represent attendance percentages, cards to highlight important information, and a sidebar for easy navigation.
 Key Features
- Student personal details
- Semester results and subject information
- Attendance percentage with progress bars
- Examination schedules
- Important announcements
- Sidebar navigation
- Dashboard cards for quick information access
Technologies Used
- HTML
- CSS
- JavaScript (if required)
Case Study 2: Library Website
Aim
To design and develop a library website that displays book categories, book covers, author details, availability labels, search and filter options, and library rules.
Description
The library website helps users explore books and find relevant information easily. CSS Grid is used to organize book categories and book covers, while structured HTML tables display catalog information. Search and filter interface elements help users locate books, and availability labels show whether books are available.
Key Features
- Different book categories
- Book covers and author details
- Book availability labels
- Search interface
- Filter options
- Book catalog displayed using structured tables
- CSS Grid layout for organizing book sections
- Library rules and guidelines
Technologies Used
- HTML
- CSS
- JavaScript (if required)
Case Study 3: Bakery Website
Aim
To design and develop an attractive bakery website that displays cakes, pastries, cookies, custom cake designs, product prices, seasonal offers, and store contact details.
Description
The bakery website presents bakery products in an attractive and user-friendly format. A visually appealing color scheme and image galleries are used to showcase products. Product prices and seasonal offers help customers explore available items, while contact details provide information about the store.
Key Features
- Cakes, pastries, and cookies
- Custom cake designs
- Product images and image galleries
- Product prices
- Seasonal offers and promotions
- Attractive color scheme
- Store contact details
- User-friendly website layout
Technologies Used
- HTML
- CSS
- JavaScript (if required)
